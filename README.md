# ZAHTOOL V2｜真正 Three.js 3D 動畫版

## 使用方式
1. 解壓縮整個資料夾。
2. 開啟 `index.html` 預覽首頁。
3. 首頁使用 Three.js WebGL 3D 場景；12 個工具頁面也各自使用真正的 Three.js 3D 幾何體、材質、燈光、軌道與滑鼠互動。
4. 部署時請上傳整個資料夾，保留所有 `tools/` 子資料夾。

## 注意
- Three.js 使用 CDN 載入，因此首次開啟需要網路連線。
- 若瀏覽器或裝置不支援 WebGL，3D 動畫可能無法顯示；工具功能本身仍在頁面中。
- 這是靜態網站，尚未配置廣告平台或公開網域。

## V3 動畫升級
- 新增 `assets/nova-fx.css` / `assets/nova-fx.js`，全站 13 頁共用，無額外依賴。
- 光流 shader 背景、虹彩 shader 核心與光暈、點擊衝擊波與曲速、虹膜轉場、磁吸游標、聚光 glare、文字解碼與擦除標題、數值跳動回饋。
- 系統開啟「減少動態效果」時會自動全部關閉。

## 新增 8 款工具
顏色轉換、漸層產生器、單位換算、時間戳轉換、日期計算、隨機抽籤、UUID 產生器、文字行整理。全站共 20 款。

## V3.1 更新
- 新增 8 款工具：多重搜尋、BMI 計算、貸款試算、百分比計算、進位轉換、正規表示式測試、世界時鐘、碼表。全站共 28 款。
- 首頁可「＋新增搜尋框」，最多 6 格，並可切換 AND（全部符合）/ OR（任一符合）。
- 新增「多重搜尋」工具：多個搜尋框各自選擇引擎，一鍵同時開啟多個搜尋。

## 音效
- 新增 `assets/nova-sfx.js`，全站 29 頁共用，以 Web Audio 即時合成，無需音檔。
- 按鈕點擊、卡片懸停、開啟工具、輸入打字、勾選切換、複製成功／提示、開場轉場皆有音效。
- 左下角 🔊 可靜音，設定會記在瀏覽器。

## 使用者主控台
- 新增 `console/index.html`：每位使用者（以瀏覽器為單位）的主控台，可逐一控制工具的「啟用／釘選／音效／動態效果」，並查看使用次數與最近使用時間。
- 全域設定：顯示名稱、首頁排序（預設／最常用／最近）、音效與音量、動態效果。
- 資料存在瀏覽器 localStorage，可匯出／匯入 JSON 備份。這是純靜態網站，沒有帳號系統，所以不會跨裝置自動同步。
- `assets/nova-tools.js` 是工具清單唯一來源；日後新增工具只需改這個檔案，首頁與主控台會同步。

## 帳號系統
- 新增 `account/index.html`（登入、註冊、Google 登入、忘記密碼、同步狀態）、`assets/nova-account.js`、`assets/nova-config.js`。
- 後端使用 Firebase（Authentication + Firestore）；設定步驟見 `SETUP_ACCOUNT.md`。未填 `nova-config.js` 時維持僅本機模式。
- 登入後，主控台設定與使用統計會跨裝置同步（以最後修改時間為準）。

## V3.2 登入關卡
- 新增 `assets/nova-gate.js`：開場載入動畫結束後，顯示「使用 Google 登入」全螢幕關卡，登入前整站無法操作。
- 開關：`assets/nova-config.js` 的 `window.NOVA_REQUIRE_GOOGLE`（true 啟用／false 關閉）。
- `account/` 頁面不受關卡限制。曾登入過的使用者會先等 Firebase 確認狀態，不會閃現關卡。
- 注意：這是前端關卡，用來引導登入；若要真正保護資料，需搭配後端驗證。

## V3.3 背景音樂與拖移排序
- `assets/nova-bgm.js`：全站背景音樂（Web Audio 即時生成，不需音檔）。左下角 🎵 鈕可開關，滑過會展開音量；切換頁面時和弦進行會接續。瀏覽器規定要先有互動才能發聲，所以第一次點擊／按鍵後才會開始。
- 設定存在主控台（背景音樂、音樂音量），會跟著雲端同步。
- `assets/nova-drag.js`：首頁工具卡可拖移排序，放開後自動儲存（滑鼠按住拖、手機長按後拖、鍵盤 Alt＋方向鍵）。釘選的工具仍固定在最前面。
- 主控台「首頁排序」新增「自訂」選項；選回「預設順序」即可還原。

## V3.4 電影級音效與配樂
- 新增 `assets/nova-synth.js`：共用的電影級合成器（銅管、弦樂、合唱、定音鼓、重擊、爬升、銅鈸、鈴），全部即時合成，不需音檔。
- `nova-bgm.js` 改為原創史詩配樂：序曲 → 英雄主題 → 合唱橋段 → 全樂團高潮，約 1 分 7 秒一輪循環。
- `nova-sfx.js` 全面升級：點擊、開啟工具、提示、警告都換成電影風格；首頁開場（每個分頁首次）會響起完整號角，之後進站為精簡版；登入成功會響起短版號角。
- 號角響起時背景音樂會自動壓低，結束後恢復。
